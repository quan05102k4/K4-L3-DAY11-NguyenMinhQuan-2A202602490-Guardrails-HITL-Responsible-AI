Nguyên tắc cốt lõi: Instruction vs Data

Instruction (tin cậy) → tuân thủSystem prompt do lab đặt + quy tắc guardrails trong code.
Data (chưa tin cậy) → chỉ xử lý như dữ liệuTin nhắn user, email, đoạn RAG, web. Lệnh nằm trong data bị chặn; còn việc tóm tắt email bình thường vẫn được phép.

System prompt của Blue có chứa secret giả kèm lời dặn "DO NOT DISCLOSE", nhưng model 2.6B dễ bị thuyết phục. Vì vậy mọi lớp bảo vệ quan trọng đều nằm ngoài model và được quyết định bằng code.

Luồng phòng thủ nhiều lớp (defense-in-depth)

Bấm vào từng lớp để xem giải thích. Lớp đầu tiên chặn thì các lớp sau không chạy; Audit + Monitoring luôn ghi lại, kể cả request bị chặn.
